# Portafolio de Heidy Cardenas

Portafolio profesional estático preparado para GitHub Pages.

## Publicación en GitHub Pages

1. Crear un repositorio público llamado `Hyasmin96.github.io`.
2. Subir `index.html`, `styles.css`, `script.js` y `favicon.svg` a la rama `main`.
3. En GitHub, abrir **Settings > Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Elegir la rama `main`, la carpeta `/ (root)` y guardar.

El sitio quedará disponible en `https://hyasmin96.github.io`.
